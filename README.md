# MD Duck

本地 Markdown 查看和审阅。选择一个文件夹，之后用任何编辑器或 AI 修改里面的文件，阅读界面会自动更新，停在原来的位置。

阅读与批注免费使用；AI 释义和翻译是可选功能，使用你自己的服务账户额度。[源码与反馈入口](https://github.com/jslynn777/md-duck) 已公开，Apple Silicon Mac 和 Windows x64 测试版的公开文件与平台要求以 [mdduck.com 下载页](https://mdduck.com/download/) 为准。

当前版本：**0.1.0-beta.5**。安装和首次打开说明见 [INSTALLING.md](INSTALLING.md)，维护者构建说明见 [PACKAGING.md](PACKAGING.md)。Mac 使用本机 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证；Windows 未进行发布者签名。

本版增加只读的整篇配对检查和问题行号定位。朗读继续使用同一模型与声音；损坏的语音片段缓存会重新合成，缓存写入失败不阻止播放，长段落分段处理并保留尾部内容。

当前提供 Apple Silicon Mac 和 Windows x64 的测试构建配置。Windows 保存锁、图片路径和原生标题栏已适配；维护者可通过 GitHub Actions 在 Windows 环境构建、测试及检查安装后的启动和朗读依赖。真实 Windows 桌面的交互、音频播放和安全提示仍需人工验收；Linux 和 Intel Mac 尚未打包验证。

## 文件约定

- 任意 Markdown 原稿都可配同目录的中文译文，例如 `notes.md` → `notes.zh.md`、`notes.markdown` → `notes.zh.markdown`，不必改名为 `article.md`。也可通过「选择已有译文」关联当前文件夹内的另一份译稿。
- AI 生成译文时，程序自动保存段落对应关系，不需要手工添加标记。手工准备的两份稿子需要精确逐段对照时，可写相同的 `<!-- block:id -->`；设置里可以复制约定。
- 图片放在文章旁边的 `assets/`，正文用相对路径。
- 每篇文章的批注和单词独立保存在旁边的 `.review/documents/`，不改动发布稿。
- 对照阅读中的提示说明实际配对方式；「检查整篇」列出全文的配对数量、标记和结构问题，点击原文或中文行号可返回对应正文。检查只读取文件，不自动配对或改写内容；结构对应不保证译文准确。

## 使用

- 顶栏「阅读排版」集中调整字号，也可恢复默认；中英文采用独立字号和行距，标题随正文同步缩放。排版菜单支持 Tab 导航和 Esc 关闭。
- 文章列表以标题为主，最多显示三行；标题下方显示相对于当前文件夹的路径，悬停可查看完整路径。右键文章或点击悬停时的「…」，可在系统文件管理器中显示、用默认应用打开、复制完整路径；有译文时可对译文执行相同操作。键盘聚焦文章后可按 Shift+F10 打开菜单，右键其他文章不会切换当前阅读内容。当前文章用中性底色和加重标题标识，设置统一在顶栏入口。
- 选中文字：翻译、朗读选中的词句、写批注。
- 段落左侧悬停或键盘聚焦时直接显示朗读、翻译、批注按钮，与正文保留 16px 间距。
- 批注面板：复制成给 AI 的修改任务，也可点铅笔编辑修改意见；保存保留原引用、创建时间和完成状态。原文改动后标为「待复核」，由你确认完成。
- 点击批注引用，会切换到引用对应的英文或中文并定位高亮；双语模式保持对照。原文或译文缺失时会提示，仍可查看和编辑意见。
- 新批注和已保存批注的修改分别保留本机草稿。批注面板顶部的「草稿」显示所属文章、语言和内容，可直接继续；关闭浮层或重启应用后仍保留。保存成功或点击「放弃草稿」后清除。
- 草稿列表可以恢复当前文件夹内其他文章的草稿。原文移走、删除或不在当前文件夹时，草稿仍可查看、复制；无法定位的新批注会暂时禁用保存，避免写到错误段落。旧版草稿兼容保留。
- 阅读时打开批注或单词面板，较窄窗口会临时收起文件侧栏；关闭面板后恢复。根据正文区域的实际宽度，已对齐段落自动切换左右或上下对照；悬停和键盘定位时轻微突出当前段落组。
- 批注采用页边意见列表；状态同时显示图标和文字，当前意见与原文用金色标记对应，修改意见中的换行完整保留。
- 界面语言在设置中切换；正文里的英文链接直接打开，普通英文单词可点击查词，拖选或双击选中文字后可翻译、朗读和批注。
- 词卡直接显示可用的英美音标、读法提示和当前原句的词义。点击「详细讲解」再查看词形、搭配、例句、联想助记及必要的易混提示；普通读、慢读和原句朗读始终可用。音标取自本地词表，多读音保留不同读法；未收录的词再查询在线词典。来源和许可见 [词表说明](src/main/data/ipa-dict/SOURCE.md)。
- 朗读继续使用本机 Kokoro q8 模型和原有五种声音，第一次请求朗读时下载约 92 MB 模型。已有缓存通过完整性检查后会复用，读过的句子也会缓存；不会在普通启动时下载。
- 语境释义和翻译使用你选择的 AI 服务，支持 OpenRouter、DeepSeek 和兼容 OpenAI Chat Completions 的自定义服务。点击英文单词时发送所选词及所在句子，点击「详细讲解」时按需补充解释；翻译词句或段落时发送对应内容。成功的词义随原句自动保存到文章对应的 `.review/documents/` 数据文件，相同词在不同原句里重新解释。没有密钥仍可阅读、批注、查本地音标和使用已准备好的本地朗读。

### 批注与单词的数据保护

- 同目录下的每篇 Markdown 独立保存批注和单词；中英对照共用源文章的数据。新格式将批注与单词放在同一份文档快照里。
- 首次打开时迁移旧版 `.review/notes.json`、`.review/words.json`，旧文件保持原样。只有一篇源文章时直接迁移；多篇时只归属能唯一匹配引用或原句的记录。无法确认归属或旧备份存在冲突的记录保留在 `.review/migration-v1.json` 的 `unassigned` 中，界面显示数量并提供文件位置。迁移清单只生成一次，新增文章不会重新分配旧数据。
- 有效数据另存一份本机备份。数据文件丢失或损坏时，显示可用备份并提供「恢复备份」；恢复前另存损坏原件。没有有效备份时，保存会被阻止并显示原因，不会写入空数据覆盖原文件。
- 重复启动会回到已有窗口；保存还使用文件事务锁，避免两个进程互相覆盖。此锁面向本机文件系统，无法确认已失效的锁不会被自动删除。
- `.review` 及其下级路径不能使用符号链接。移动文章时一起保留 `.review` 目录；文章改名后，在新文章中可预览旧文件的批注/单词记录并手动关联；关联会保留旧快照，不覆盖已有数据。

## 连接自己的 AI 服务

在设置的「AI 服务」中选择服务：

- **OpenRouter：** 点击「在浏览器中连接 OpenRouter」，登录并授权后返回程序，无需手动复制密钥；也可从 [OpenRouter 密钥页面](https://openrouter.ai/keys) 创建密钥并粘贴。
- **DeepSeek：** 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建 API 密钥后粘贴，接口地址和默认模型已预填。
- **自定义服务：** 粘贴该服务的密钥，在「高级设置」填写兼容接口的基础地址和模型名。地址通常形如 `https://api.example.com/v1`，不带 `/chat/completions`。

先点「保存配置」，再点「测试连接」，看到「连接可用」后即可使用。测试发送一条很短的请求，可能产生少量费用。浏览器授权完成后也会自动测试；密钥已保存不代表连接可用。密钥、额度、模型或网络出现问题时，按提示修复后重新测试。每个服务分别保存自己的配置，切换服务后仍需保存选项。

调用使用你自己的服务账户额度；网页聊天会员不一定包含 API 额度。密钥保存在本机，通过系统安全存储加密，不会在界面回显；无法安全保存时会提示。可用「清除此服务密钥」移除本机保存的密钥。服务商账户内的密钥管理与撤销仍由用户自行操作。

## 生成缺失的中文译文

已配置 AI 且文章没有对应中文译文时，正文上方会提供「生成中文译文」。没有密钥时正常阅读；主动切换「中文」或「对照」后，可选择已有译文或「连接 AI」。

1. 点击「生成中文译文」，查看当前服务和模型，再点击「开始翻译」。文章正文会分段发送到所选服务，费用由该服务账户承担。
2. 界面显示已完成段数，可点「停止」。已完成部分保存在文章旁的 `.review/translations/`，下次打开可继续；失败后修复问题再重试。
3. 完成后另存中文 Markdown，点击「打开对照」开始阅读。原文不改动，已有译文不覆盖。

原文、服务地址或模型变化后，会按新条件重新翻译，避免把旧进度混入新译文。进度和对应关系保存在 `.review/translations/`，使用资料库内的相对路径；整体移动文章、译文和 `.review/` 后，可继续读取关联及原条件下的进度。单独移动文件或修改原稿仍需重新关联或开始翻译。AI 译文仍需结合原文检查。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `1` / `2` / `3` | 原文 / 中文 / 对照 |
| `B` | 打开或关闭批注面板 |
| `⌘,` | 设置 |
| `⌘O` / `⇧⌘O` | 打开文件夹 / 打开单个文件 |
| `Esc` | 关闭浮层，停止朗读 |
| `⌘↩` | 保存批注 |

# mdduck.com 部署说明

## 产物

在本目录运行 `npm ci`、`npm run check`、`npm run build`、`npm run verify`。上传 `dist/` 内的内容作为网站根目录，不要上传整个项目、`node_modules/` 或桌面程序的数据目录。

本网站是静态站点。可以由服务器现有 Nginx、Caddy 或其他静态文件服务托管，无需启动 Astro/Node 进程。具体配置在确认现有服务器、站点目录和 HTTPS 方案后再执行。

## 站点需要的行为

1. `https://mdduck.com/` 显示中文首页，`https://mdduck.com/en/` 显示英文首页。
2. `/guide/`、`/download/`、`/en/guide/`、`/en/download/` 分别读取相应目录的 `index.html`；目录页面的无尾斜杠地址重定向到带尾斜杠版本。中英文页面都应可直接访问，不依赖浏览器语言或客户端脚本跳转。
3. 普通未知地址返回中文 `404.html`，`/en/` 下的未知地址返回英文 `en/404/index.html`，HTTP 状态均为 404。两份错误文档作为 nginx 的内部错误响应；直接访问 `/404.html` 或 `/en/404/` 也返回 404。按语言回落必须配置并验证服务器规则，不会仅因英文文件存在而自动生效。不要把未知路径重写为首页，也不要将错误响应改成 200。
4. 主站域名固定为 `mdduck.com`，HTTP 重定向到 HTTPS；如同时启用 `www.mdduck.com`，重定向到主站。
5. `robots.txt` 与 `sitemap.xml` 可直接访问。站点地图包含 6 个正文页面的中英地址与 hreflang，不包含两份错误页面。
6. HTML 和非哈希文件（图片、示例 ZIP）不设置永久缓存；`/_astro/` 中带内容哈希的文件可长期缓存。
7. 示例 ZIP 和安装包返回正确的文件类型。安装包可放在独立的 `downloads/` 目录，版本化文件名在上传后不覆盖；支持完整下载并核对 SHA-256。对较大文件检查 HTTP Range 响应，便于中断后继续下载。

## 发布与回滚

先上传到新的版本目录，验证完整后再切换站点根目录或 `current` 链接。保留上一份产物用于回滚。不要在没有备份的情况下覆盖现有网站或修改其他站点配置。

每次上线前读取现有服务器配置与当前网站状态，确认站点目录和 HTTPS 不受其他站点影响。公开安装包不是介绍站上线的技术前提；安装包尚未验收时，页面保持准备状态。

当前 `0.1.0-beta.5` 按免费测试版发行，官网仅提供 Mac arm64 DMG 与 Windows x64 Setup。Mac 使用 ad-hoc 临时签名，没有 Developer ID 签名或苹果公证；Windows 没有发布者签名。保持中英文下载页与指南的安装提示。发布前核对源码版本、项目许可证和第三方声明，确认对应原生依赖的许可与源码材料，再验证平台包结构、安装与启动、朗读依赖、完整 HTTP 下载和 SHA-256。未完成这些检查时，`release.status` 保持 `preparing`。

上传顺序：先把已经验收的安装包与同版本对应源码/朗读构建材料上传到版本目录，读取公开 HTTPS 下载 URL 并核对字节和哈希；然后填写 `src/data/release.ts` 的两条 `artifacts` 和 `sourceUrl`，将状态设为 `published`，重新构建并验证网站。两条安装包记录分别使用 `kind: 'mac-dmg'` 与 `kind: 'windows-setup'`，文件名须包含同一版本号和平台名；源码归档文件名为 `MD-Duck-{version}-Corresponding-Source.tar.gz`。源码归档在开源区域显示普通下载链接，准备状态不显示占位链接。不要公开 Portable 测试包，也不要在同一个版本 URL 下替换二进制。最后切换网站版本目录并保留回滚版本。

## 上线后验证

- 检查主域名、HTTP/HTTPS、可选 www 重定向。
- 实际打开中英文首页、指南和下载页，确认 6 个页面均可直接访问；逐页切换语言应到达对应页面。静态语言切换不保证保留当前 `#片段` 或滚动位置。
- 分别访问中文和 `/en/` 下不存在的路径，确认显示对应语言的错误页且 HTTP 状态为 404；再检查 `/404.html`、`/en/404/` 及错误页语言入口。
- 检查正文页面的 HTML `lang`、canonical、`zh-CN` / `en` / `x-default` hreflang 与站点地图地址一致，两份错误页面保留 `noindex`。
- 手机与电脑检查无横向溢出，页面导航和目录锚点可使用。
- 下载示例 ZIP，检查两份 Markdown 完整且没有额外本机文件。
- 确认生产页面没有开发工具、第三方统计脚本或私有文件。
- 若发布安装包，另外校验实际下载的大小、SHA-256、Content-Type、下载文件名和 Range 响应；确认中英文下载页提供完全相同的文件与校验值，按钮对应正确的系统、芯片和安装步骤。Windows 桌面体验、完整朗读和首次模型下载未实际验收时，保留页面中的范围说明。

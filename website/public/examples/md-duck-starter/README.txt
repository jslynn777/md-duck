MD Duck practice library / MD Duck 练习文章库

English
1. Extract the ZIP before opening it. On Mac use Finder; on Windows choose Extract All in File Explorer.
2. Open MD Duck. Choose File > Open Folder (Mac: Command O; Windows: Ctrl O) and select this md-duck-starter folder.
3. Open 01-a-slower-morning. Choose side-by-side reading. Select “not far away”, annotate it and save (Mac: Command Return; Windows: Ctrl Enter).
4. Open Notes, choose Copy open to copy the unfinished comment and give it to your AI or editor. Ask for a more specific distance in BOTH article.md and article.zh.md. Keep the block markers unchanged. Save the files in the same folder.
5. Return to MD Duck. Local changes refresh automatically. Re-read the updated passage, review the comment and mark it complete when resolved. Use Check whole document to check the bilingual structure.
6. Open 02-a-good-question and try another comment. You can use the article menu to archive the practice article and restore it from Archived.

Files: each article folder contains English article.md, Chinese article.zh.md and local assets. Number prefixes give the series a clear name order. The diagrams are simple illustrations, not photographs. Ordinary reading and annotations need no AI connection in MD Duck. AI services are optional and use your account. Listening may download its model on first use.

Keep the whole article folder when moving files. After using MD Duck, hidden .review and .mdduck directories may appear; preserve them with backups. Never ask an AI to rewrite those directories. Unsaved drafts and app settings remain on this computer.

Full guide and ready-to-copy writing/revision prompts: https://mdduck.com/en/guide/

中文
1. 先解压 ZIP。Mac 使用 Finder；Windows 在文件资源管理器中选择“全部解压缩”。
2. 打开 MD Duck，选择“文件 > 打开文件夹”（Mac：Command O；Windows：Ctrl O），选中这个 md-duck-starter 文件夹。
3. 打开 01-a-slower-morning，切到双语对照。选中“并不远”，留一条批注并保存（Mac：Command Return；Windows：Ctrl Enter）。
4. 打开批注，复制未完成意见，交给你使用的 AI 或编辑器。让它把距离写具体，并同时修改 article.md 和 article.zh.md；保留已有段落标记，保存到原文件夹。
5. 回到 MD Duck，本地保存后会自动刷新。重新阅读改动，复核批注，确认解决后标为完成。使用“检查整篇”检查双语结构。
6. 打开 02-a-good-question，再试一条批注。可从文章菜单归档练习文章，再从“已归档”恢复。

每个文章文件夹包含英文 article.md、中文 article.zh.md 和本地 assets 图片。文件夹数字前缀便于按名字看清系列顺序。图为简单示意，不是照片。普通阅读和批注不需要在 MD Duck 中连接 AI。AI 功能可选，使用自己的服务账户；首次朗读可能需要下载声音模型。

移动时保留完整文章文件夹。使用后可能出现隐藏的 .review 和 .mdduck 目录，备份时一起保留，不要让 AI 改写。未保存草稿和程序设置保存在当前电脑。

完整指南及可复制的写作、修改提示词：https://mdduck.com/guide/
